# 🍎 Apple Store Landing Page Clone

A responsive clone of the Apple Store landing page, built with pure HTML5 and CSS3.

## 🌐 Live Demo

👉 **[View Live Demo](https://behnaz-ahmadpour.github.io/apple-store-clone/)**

## ✨ Features

- 📱 Fully responsive design (mobile, tablet, desktop)
- 🧭 Sticky header with mobile hamburger menu
- 🎠 Horizontal product slider with smooth scroll
- 🎨 Modern layouts with CSS Grid & Flexbox
- 🖼️ Full-screen hero banner with gradient overlay
- 📰 Article cards with clean typography
- 🦶 Multi-column responsive footer
- 🍎 Apple logo as inline SVG

## 🛠️ Tech Stack

- HTML5 (semantic markup)
- CSS3 (Flexbox, Grid, Media Queries, CSS Variables)
- SVG (scalable Apple logo)
